# Security policy

Report a vulnerability in the Comunicate.eu MCP server, API or website by email to **contact@comunicate.eu**, with "Security" in the subject. Please include the affected address, the steps to reproduce and the impact you see.

- We acknowledge reports within 3 working days and keep you informed until the issue is fixed.
- Please do not access or change other people's data, and do not run load or denial-of-service tests.
- Machine-readable contact: <https://comunicate.eu/.well-known/security.txt> (RFC 9116).

This repository contains documentation and manifests only; the platform itself is closed source.
